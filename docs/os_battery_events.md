# OS 分侧电池事件

OS 通过 `SET_BAT_VOLT_CHANGED` 分别发送主侧和从侧的电池快照。
事件 ID 不变，payload 替换为 OS SDK `elf_common.h` 中的 `jyt_battery_report_t`，长度为 8 字节：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| side | uint32_t | 0：主侧/右腿；1：从侧/左腿 |
| state.bat_chg_combo.soc | uint8_t | 该侧经 OS 重标定的显示电量，0–100% |
| state.bat_chg_combo.charger_mode | uint8_t | 该侧充电模式，沿用 OS 定义 |
| state.bat_chg_combo.voltage_mv | uint16_t | 该侧电压，mV |

OS 对两侧分别按电量和充电模式去重。某侧尚无有效数据时不发送该侧，另一侧可以先上报。
纯电压变化不触发消息，缓存电压代表最近一次收到的快照。

jy_app 严格校验消息长度、侧别、电量范围和非零电压，再分别缓存。
`system_get_battery_state_by_side()` 提供按侧读取接口；未收到该侧时返回 false，不修改输出参数。
缓存中的充电模式按同侧配件状态修正：该侧配件为 `case` 时固定为 1，不采信该侧电池上报的充电模式，电量和电压仍正常更新。
该侧配件由 `case` 变为非 `case` 时，先将该侧充电模式置 0，不恢复旧值；直到该侧下一次有效电池上报才重新采用上报值。
其他侧的上报不会恢复该侧退出 case 前的旧充电状态，重复非 case 配件消息也不会清除之后收到的新充电状态。
显示始终取最低电量侧：高电量侧在 case 中，不会强制低电量侧显示充电；电量相等仍取从侧。
配件事件不算电池上报，双侧电量未收齐时仍隐藏电池及充电图标。
最终选中侧进入充电状态时，无论由电池还是配件事件触发，都取消已显示或等待亮屏显示的低电量提示。
充电期间收到低电告警不再显示；亮屏补显时再次检查当前充电状态，避免旧提示残留。
启动后必须收到主、从两侧的有效快照，才选较低电量侧的完整快照同步状态栏（电量相等选从侧）。
两侧均未上报或只有一侧上报时，只缓存、不刷新聚合电池状态，沿用状态栏未就绪时隐藏电池图标和百分比的行为；
不会先显示单侧电量，也不会补报默认 0% 或单侧电量。先到侧的多次更新保留最新值，另一侧补齐后一次显示正常电量。
两侧均已上报后，任意侧更新都会重新选择；真实 0% 有效，非法消息不覆盖已有缓存。
本次不处理通信中断，也不按上报间隔设置超时失效。
手机电量仍使用聚合最低值；`chargeState` 保留最低电量侧的聚合充电状态（0/1），新增 `chargeStateBySide` 表示双侧位图。
双侧位图中 bit0 表示主侧充电，bit1 表示从侧充电：0 为均未充电，1 为仅主侧，2 为仅从侧，3 为双侧充电；每侧只认修正后的 `charger_mode == 1`。
`onChargeStateChanged`、`getChargeState` 和 `getAll` 均返回两个字段，编码一致。
双侧未就绪时不主动上报充电位图，`getChargeState`、`getAll` 和 `getBattery` 返回 `ErrNotReady`；双侧就绪后的真实 0% 正常返回。
手机未连接仅缓存；每次建立连接后补报最新聚合状态和双侧位图（包括 0）；连接期间任一字段变化都上报两个字段。
眼镜盒电量统一要求手机已连接、当前存在 case 且已收到盒子电量。先收到盒子电量、后收到 case 配件时，进入 case 立即补报缓存；未连接时仍只缓存，无缓存或重复 case 事件不触发补报。
即使双侧位图不变，仅电量交叉导致最低侧切换并改变聚合充电状态，也必须上报。
成功发送才更新去重记录，失败后在后续电池/配件更新或重连时重试。本地状态栏和低电量提示仍使用最低电量侧的单侧充电模式。

这属于 OS 与 jy_app 之间的消息格式变更，必须使用重新导出的 OS SDK 配套构建、部署两端。
旧的 4 字节聚合消息不再接受。

模拟器 FIFO 指令（电量均为显示百分比）：

- `SET_BAT_STATUS 80 0`：主侧 80%，未充电。
- `SET_BAT_STATUS_SLAVE 35 1`：从侧 35%，充电中。
- `SET_BAT_SOC 60`、`SET_CHARGER_ON`、`SET_CHARGER_OFF`：修改主侧对应字段。

模拟器事件面板保留单组电量及充电控件，通过 `Left`（从侧/左腿）和 `Right`（主侧/右腿）单选指定操作侧，默认 Right。
SOC 的 `Send`、0/20/50/80/100% 快捷按钮及 `charger` / `nocharger` 按钮均只发送当前选中侧的完整快照。
两侧电量和充电状态分别缓存；切换侧别恢复该侧输入、不发送事件。启动或手动编辑电量也不会自动发送，快捷电量和充电按钮则沿用原有点击即发送的行为。
`nocharger` 发送模式 0，`charger` 发送模式 1；配件为 case 时仍由 jy_app 覆盖同侧充电状态。
`Case SOC` 独立发送眼镜盒电量；配合 Host 连接/断开及 Attachments 左右侧切换验证缓存、重连补报与 case 门控。

可先注入主侧 100%，确认仅缓存、状态栏仍隐藏电池，再注入从侧 60%，确认直接显示 60%，没有先显示 100% 的过程。
重启模拟器反向注入两侧，行为应一致；重复更新先到侧不能提前显示，补齐另一侧时应使用双方最新缓存。
两侧就绪后，仅改变高电量侧充电模式时，该侧缓存应更新，状态栏仍取低电量侧；0% 正常显示。
